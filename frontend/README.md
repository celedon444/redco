# REDCO — Frontend

SPA desarrollada con React + Vite + TypeScript + Tailwind CSS.

---

## Estructura

```
src/
├── assets/       → Recursos estáticos (imágenes, íconos, fuentes)
├── components/   → Componentes reutilizables de UI
├── layouts/      → Layouts base de la aplicación
├── pages/        → Páginas (una por ruta principal)
├── routes/       → Definición de rutas de la aplicación
├── services/     → Llamadas a la API (axios / fetch)
├── hooks/        → Custom hooks de React
├── types/        → Tipos e interfaces TypeScript
├── utils/        → Funciones utilitarias
└── App.tsx       → Componente raíz
```

---

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tests

```bash
# Unitarios
npm run test

# E2E
npm run test:e2e
```
